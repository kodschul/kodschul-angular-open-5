# eventhub-ui-consumer (Lab 11.2)

Kleine Angular-22-App, die das UI-Kit `eventhub-ui` als npm-Paket nutzen soll. Ausgangszustand: Badge und Ticket-Zähler sind noch einfache HTML-Elemente (`TODO Lab 11.2` in `src/app/app.ts`).

## Start

```bash
npm install
# nach Build und npm pack in ../eventhub-ui-lib:
npm install ../eventhub-ui-lib/dist/eventhub-ui/eventhub-ui-0.1.0.tgz
npx ng serve                             # http://localhost:4220
```

Lösung: `output/m11-libraries/l02-library/l02-library-sol.md`.
